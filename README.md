# ScrapeGuard AI

ScrapeGuard AI is a self-healing job intelligence platform that uses a custom Bright Data Scraper Studio scraper to detect website changes that cause scraper failures and automatically heal the scraper.

## Hackathon

WeMakeDevs × Bright Data Scrape-Verse Hackathon

## Planned technology stack

- React + TypeScript
- FastAPI
- PostgreSQL
- Bright Data Scraper Studio
